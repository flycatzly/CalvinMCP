# 常用分析模板库（模式 B 复用）
> 版本 v1.4.2 · sql-check-script · 更新记录见 README.md「更新记录」

写 SQL 前先查这里；命中模板直接套用并替换表名/字段。

## 1. 状态分布（回归后核对）

```sql
-- 统计各订单状态的数量，排查回归后是否有异常堆积
SELECT
    status AS 订单状态,
    COUNT(*) AS 订单数,
    ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 2) AS 占比_百分比
FROM orders
GROUP BY status
ORDER BY 订单数 DESC;
```

## 2. 环比对比（按天趋势）

```sql
-- 按天对比数据量，排查环比异常
SELECT
    DATE(created_at) AS 日期,
    COUNT(*) AS 当日数量
FROM orders
WHERE created_at >= CURRENT_DATE - INTERVAL 7 DAY
GROUP BY DATE(created_at)
ORDER BY 日期;
```

> 方言差异：`INTERVAL 7 DAY` 为 MySQL 写法；PostgreSQL 用 `INTERVAL '7 days'`。

## 3. 空值核查

```sql
-- 核查关键字段空值/缺失
SELECT
    COUNT(*) AS 总行数,
    COUNT(mobile) AS 手机号非空,
    COUNT(*) - COUNT(mobile) AS 手机号缺失
FROM orders;
```

## 4. 重复核查

```sql
-- 查重复订单号
SELECT order_no, COUNT(*) AS 出现次数
FROM orders
GROUP BY order_no
HAVING COUNT(*) > 1
ORDER BY 出现次数 DESC;
```

## 6. 数据质量检查（脏数据 / 异常值 / 缺失值）

### 异常值：未来时间

```sql
-- 创建时间在未来（时钟异常或脏数据）
SELECT COUNT(*) AS 异常条数 FROM orders WHERE created_at > NOW();
```

### 异常值：负数 / 超范围

```sql
-- 金额为负
SELECT COUNT(*) AS 异常条数 FROM orders WHERE amount < 0;
```

### 枚举越界

```sql
-- status 出现未定义值
SELECT status, COUNT(*) AS cnt
FROM orders
WHERE status NOT IN ('待支付','已支付','已发货','已完成','已取消')
GROUP BY status;
```

### 判定口径

- 缺失率 > 5%（关键字段）→ 报异常
- 未来时间 / 负数金额 / 枚举越界 → 一律报异常（P1+）
- 缺失值核查见第 3 节

## 7. 脱敏写法（必须以 SQL 实现，禁止原样输出）

| 列 | MySQL | PostgreSQL |
|----|-------|------------|
| mobile | `CONCAT(LEFT(mobile,3),'****',RIGHT(mobile,4)) AS mobile` | `LEFT(mobile,3) \|\| '****' \|\| RIGHT(mobile,4) AS mobile` |
| id_card | `CONCAT(LEFT(id_card,3),'***********',RIGHT(id_card,4))` | `LEFT(id_card,3) \|\| '***********' \|\| RIGHT(id_card,4)` |
| email | `CONCAT(LEFT(email,1),'***@',SUBSTRING_INDEX(email,'@',-1))` | `LEFT(email,1) \|\| '***@' \|\| split_part(email,'@',2)` |

> 无法脱敏时直接**排除该列**（不写进 SELECT），禁止原样输出。

## 8. 多库对比（测试库 vs 影子库 / 新旧环境）

同实例内跨库用 `库名.表名`：

```sql
-- 同实例跨库：对比两库订单量差异
SELECT
    (SELECT COUNT(*) FROM test_order_db.orders)  AS 测试库订单数,
    (SELECT COUNT(*) FROM shadow_user_db.orders) AS 影子库订单数;
```

> 跨实例时对两个 source 分别执行，再在报告中对比。

## 9. 接口前后对比（版本间数据变化）

```sql
-- 对比两个时间窗口的数据量，排查新版本少写/多写
SELECT
    CASE WHEN created_at >= '2026-09-01' THEN '新版本' ELSE '旧版本' END AS 版本,
    COUNT(*) AS 订单数
FROM orders
WHERE created_at >= '2026-08-25'
GROUP BY 版本;
```

## 10. 日志排查（异常刷量）

```sql
-- 单用户单日操作次数 Top，排查异常刷量
SELECT
    user_id,
    DATE(created_at) AS 日期,
    COUNT(*) AS 操作次数
FROM user_action_log
WHERE created_at >= CURRENT_DATE - INTERVAL 7 DAY
GROUP BY user_id, DATE(created_at)
HAVING COUNT(*) > 1000
ORDER BY 操作次数 DESC;
```
