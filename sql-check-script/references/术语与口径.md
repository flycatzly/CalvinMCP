# 术语与口径速查
> 版本 v1.4.28 · sql-check-script · 更新记录见 README.md「更新记录」

统一术语理解，避免不同 Agent / 不同会话判定不一致。

| 术语 | 含义 |
|------|------|
| 区分度 | 某字段取值的集中程度。某取值占比越高，区分度越低，用它过滤越没价值（如 status=1 占 80%） |
| 扫描行数比 | `EXPLAIN rows` ÷ 实际返回行数；> 100 记 P1，> 1000 记 P0 候选 |
| 全表扫描 | `type=ALL`（MySQL）/ `Seq Scan`（PG），未走索引 |
| filesort | MySQL 排序未走索引（`Extra=Using filesort`），需额外排序开销 |
| 覆盖索引 | 查询所需列全在索引中（`Extra=Using index` / `Index Only Scan`），无需回表 |
| 回表 | 通过二级索引拿到主键后再查主键索引取数据 |
| 深分页 | 大偏移分页如 `limit 100000,20`，需扫描并丢弃大量行 |
| 口径 | 统计边界定义：时间范围、是否去重、是否含取消/异常态、分组维度 |
| 先审后执行 | SQL 必须先展示给用户并获得确认，才可执行 |
| 白名单 | `allowed_databases` / `allowed_tables`；白名单外的库表一律拒绝 |
| 脱敏 | 敏感字段以 SQL 变形输出（如 138****1234）；无法脱敏则排除该列 |
| 证据优先 | 实测（EXPLAIN / describe_table）覆盖静态信号规则 |
| 待验证 | 拿不到证据时的标注，禁止当作确定结论 |
| P0 / P1 / P2 | 风险等级，判定标准见 `风险等级定义.md` |
| 模式 A / 模式 B | A = 全链路 SQL 质量检测；B = 只读数据分析 |
