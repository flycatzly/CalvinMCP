# sql-check-script 部署说明

> 版本 v1.4.28 · sql-check-script · 更新记录见 README.md「更新记录」

SQL 全链路质量检测 + 只读数据分析 Skill。**本包零 npm 依赖**，解压/拷贝即可部署；依赖的本地 MCP `calvin-db-mcp`（v1.6.22）由其 `install.mjs` 一条命令装好（依赖也在那条命令里用 `npm ci` 生成）。

## 快速命令索引（速查）

```powershell
# 一键验收（selftest + sqlite-validate + mysql-validate(门控) + docsync + config-lint + E2E 合并裁决；安装后快速回归入口）
node tests\run_all.mjs

# 全链路 E2E 单跑（可选 live 段：FULLCHAIN_MYSQL=1 / FULLCHAIN_PG=1）
node tests\fullchain_test.mjs
```

## 你要做的只有 3 步

```powershell
# 1) 复制到技能目录
Copy-Item -Recurse -Force "<解压目录>\sql-check-script" "$env:USERPROFILE\.agents\skills\sql-check-script"

# 2) 部署依赖的 MCP（自动生成依赖 + 导入连接 + 自检 + E2E + 注册，详见同级 calvin-db-mcp\部署说明.md）
cd <解压目录>\calvin-db-mcp
node install.mjs "C:\path\to\your.dbp"

# 3) 重启 MCP 客户端，完成
```

无 `.dbp` 时先 `node install.mjs` 看初始化指引，导入后重跑即完成注册与验收。

## 纯净包里有什么（和没有什么）

- 本包**零 npm 依赖**：不需要 `npm ci`、不需要联网；`tests\run_all.mjs` 验收自依赖（selftest 用同级 `calvin-db-mcp`，E2E fixture 用同级 `demo.db` 自供给）
- **不随包**：`node_modules`、任何 `.` 前缀文件/目录（`.git`/`.gitignore`/`.zcode` 等）、开发机路径与临时产物、凭据——拷贝即部署
- MCP 侧依赖（`mysql2`/`pg`）由命令生成：`calvin-db-mcp` 的 `install.mjs` 自动执行 `npm ci --omit=dev`（首次需可访问 npm 源；内网加 `--registry` 镜像），`.gitignore` 等也在装机导入 `.dbp` 时自动生成

## 怎么算装好了

| 检查 | 通过标准 |
|------|----------|
| 技能被发现 | 客户端技能列表出现 `sql-check-script` |
| MCP 已注册/初始化 | 工具列表出现 `db` 的 16 个工具；`list_sources` 返回源列表（非 `init_required`） |
| 一键验收 | `node tests\run_all.mjs` 末行 `RUN_ALL selftest=… sqlite-val=… mysql-val=… docsync=… config-lint=… e2e=… … => OK` |

完整判定表见 README「验证装好了」。**验收线以 0 failed 为准**，勿以 passed 数为验收线（对方 selftest 双口径两态计数、随版本新钉与源连通性增长，导入 `.dbp` 另有增量钉，均以当日实测为准；计数归属见 `references\验收清单.md` 部署自检 selftest 项「计数归属」注记）。

## 出问题先看这几条

| 现象 | 原因 | 动作 |
|------|------|------|
| `list_sources` 返回 `init_required` | 还没导 `.dbp` | `calvin-db-mcp` 下 `node install.mjs <你的.dbp>` |
| 客户端技能列表没有本技能 | 复制目录不对/没重启 | 核对技能目录路径，重启客户端 |
| `run_all` 末行 `=> FAIL` | 看 FAIL 段输出定位 selftest 还是 E2E | 详见《部署说明.详细版.md》七、问题排查；现象级问题见 `references\故障处理.md`；报错码反查见 `references\故障处理.md` §五矩阵表 |
| E2E 整段 SKIP | demo fixture 双缺（配置无 demo 源且无 `demo.db`） | 部署布局保留同级 `calvin-db-mcp\demo.db` 即可自供给 |

## 安全红线（部署即生效，不可关闭）

仅只读（SELECT/WITH/SHOW/DESCRIBE/EXPLAIN）；永不执行 INSERT/UPDATE/DELETE/DROP/TRUNCATE/ALTER（技能与 MCP 双层拒绝，即使用户要求）；`execute`/`create_table`/`import_data` 一律禁用；不碰生产库；仅白名单库表；敏感字段（手机号/身份证/邮箱）脱敏或排除（A/B 模式均生效）；任何 SQL 先展示用户确认再执行；结果预计 >5000 行先 COUNT 再抽样；防幻觉 SQL（先 `describe_table` 取真实 schema）；PRE/UAT 取证前二次确认环境；最小权限 SELECT-only 账号；无证据输出「待补充/待验证」禁止猜根因。
