## 一、风险概览（Top 问题）

按 P0 → P1 → P2 列出最严重的 N 条，每条一句：什么 SQL、为什么危险、怎么修。

## 二、SQL 明细

每条 SQL 一张小卡片：

- **调用链**：Controller → Service → Mapper → SQL
- **原始 SQL**（参数脱敏）
- **八步结论摘要**：命中风险 + 关键证据（EXPLAIN type/key/rows/Extra、count_rows 区分度）
- **风险等级**：P0/P1/P2
- **优化建议**：附 EXPLAIN 前后对比验证方式

## 三、表级发现

- 缺索引的表 / 建议补的联合索引 `(col1, col2)`
- 大表清单（行数 > 阈值，含预估行数）
- 脏数据 / 异常值 / 缺失值样例（sample_data 证据）

## 四、一致性检测结果

- 多表状态不一致样例（订单 vs 流水 vs 库存等）+ 比对 SQL + 风险等级
