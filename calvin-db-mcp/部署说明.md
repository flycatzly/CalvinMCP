## 快速命令索引（速查）

```powershell

node mcp\selftest.mjs

# 只导入连接（--force 覆盖已存在的配置）
```

## 安装器自动完成的事（不用你操作）

| 自动做的事 | 说明 |
|---|---|
| Node 版本检查 | 低于 18.17 直接报错退出 |
| 安装运行时依赖 | `npm ci --omit=dev`，26 个纯生产包（纯净包不含 `node_modules`）|
| 导入连接配置 | 解包 `.dbp`、解密凭据、过滤 MySQL/PG/OceanBase、**加密写入** `mcp/dbmcp.config.json`（无明文）|
| 连通性预检 | 逐主机 TCP 探测，标注 可达 / 需VPN·白名单 |
| 功能自检 | `node mcp/selftest.mjs`，失败即报错 |
| 注册 MCP 客户端 | Claude Code（CLI 或 `~/.claude.json`）、Claude Desktop、Cursor；改前自动备份 `.bak-calvin-db-mcp` |
| 保护凭据 | 生成 `mcp/.gitignore`（已存在则只追加，不覆盖）|

> 纯净包 = 零预装依赖（不含 `node_modules`，依赖由命令生成）、不含任何 `.` 前缀文件/目录、不含任何凭据。上面第 2、3 项就是把它补齐，无需手工准备。

## 怎么算装好了

| 检查 | 通过标准 |
|---|---|
| 安装器输出 | `INSTALL_STATUS=OK` 且 `FAIL=0` |
| 配置 | `mcp/dbmcp.config.json` 存在，含 `enc`、无明文 `url` |
| 客户端 | 重启后出现 `db` 服务器，能列出 16 个工具 |
| 实测 | 让模型调 `list_sources`，返回你导入的源数量 |

**自测数字对不上不用慌**（都算成功）：

| 情况 | 汇总行 |
|---|---|
| 还没导入配置 | `263 passed, 0 failed` |
| 已导入（部分源不可达也同理）| `277 passed, 0 failed` |

打印 `SKIP` 是正常的（未初始化、无口令、缺某个源时都会 SKIP 并计入通过）；只要没有 `FAIL` 就是好的。

## 出问题先看这几条

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 工具回 `init_required` | 还没导入配置 | 按上面第 2 步带上 `.dbp` 路径重跑 |
| 依赖装不上（`ETIMEDOUT`）| 连不上 npm | 加镜像重跑：`npm ci --omit=dev --registry=https://registry.npmmirror.com`（在 `mcp\` 下执行）|
| `ECONNREFUSED` / `ETIMEDOUT` | 库不通 | 连 VPN / 加 IP 白名单；`find_database` 传 `probe: true` 先探测 |
| 客户端里没有 `db` | 没重启或没装技能 | 完全退出客户端再启动；确认技能进了 `~/.agents/skills/` 或 `~/.claude/skills/` |
| `Access denied for user` | 账号或口令 | 用最小权限账号；确认 DBeaver 勾了「保存密码」后重新导出导入 |
| 自测出现 `FAIL` | 配置坏了或 `crypt.mjs` 被换 | 重新导入配置；确保用的是本包配套的 `crypt.mjs` |

> 更细的排查见 `SKILL.md` 的「排错速查」；配置项与红线细节也在那里。
> 实在卡住时，把这三样发出来最快定位：`node install.mjs` 的完整输出、`mcp/dbmcp.config.json` 里源的数量（**别发内容**）、以及报错的原文。

## 手动兜底（只有自动失败时才需要）

```powershell
cd "$env:USERPROFILE\.agents\skills\calvin-db-mcp\mcp"

npm ci --omit=dev --no-audit --no-fund         # 只装依赖
node import-dbeaver.mjs "C:\path\to\xxx.dbp"  # 只导入连接（--force 覆盖已有配置）
node selftest.mjs                              # 只跑自检
node crypt-cli.mjs encrypt                     # 明文 url → enc（改完配置后用）
node crypt-cli.mjs decrypt                     # enc → 明文（临时查看）
```

注册片段（客户端要求手工填时）：

```json
{ "mcpServers": { "db": { "command": "node", "args": ["<技能目录>\\mcp\\server.mjs"] } } }
```

> 需要 `export_data` / `import_data` 时，在注册 JSON 里加 `"env"` 块设置 `DBMCP_EXPORT_DIR` / `DBMCP_IMPORT_DIR`
> （import 未设置时回退 EXPORT_DIR）——写法示例见《部署说明.详细版.md》环境变量表。

| 客户端 | 配置文件 |
|---|---|
| Claude Code | `~/.claude.json`，或命令行 `claude mcp add db -s user -- node "<技能目录>\mcp\server.mjs"` |
| Claude Desktop | `%APPDATA%\Claude\claude_desktop_config.json` |
| Cursor | `~/.cursor/mcp.json` |

误改了客户端配置，用备份恢复：

```powershell
Copy-Item "$env:USERPROFILE\.claude.json.bak-calvin-db-mcp" "$env:USERPROFILE\.claude.json" -Force
```

## 两个开关（默认都关闭）

| 开关 | 作用 |
|---|---|
| `--allow-writes` | 放开 `execute`（INSERT/UPDATE/DELETE）。安全红线仍强制生效 |
| `--allow-create-table` | 放开 `create_table`（单条 CREATE TABLE）|

也可以导入后直接改 `mcp/dbmcp.config.json`：`allowWrites` / `allowCreateTable` / `maxAffectedRows`（写操作行数预检，默认 500）/ `maxRows`（单次查询上限，默认 200）。
