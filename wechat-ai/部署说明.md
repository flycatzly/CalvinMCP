# wechat-ai 部署说明

> **v1.0.1** · MCP server 1.0.1 · 63 个工具 · 12 套件 368 断言 · 版本记录见 README「版本记录」

纯净发布包（剔除开发机残留，**无 `node_modules`、无 `.` 前缀目录**），解压 / 拷贝即可部署。零 npm 依赖——不需要 `npm install`、不需要联网、不需要生成任何依赖。

详细版（数据源配置、报告产物、排障、卸载、安全边界）见 [部署说明.详细版.md](./部署说明.详细版.md)。

## 快速命令索引（速查）

```powershell
# 安装 / 注册（环境检查 → 自检 94 断言 → 注册 MCP 客户端）
node install.mjs
# 只检查与自检，不改任何客户端配置
node install.mjs --no-register
# 只打印将要写入的客户端配置
node install.mjs --dry-run
# 查看全部 63 个工具
node mcp\server.mjs --list-tools
# 单独跑自检（末尾必须是 0 failed）
node mcp\selftest.mjs
# 全量验证（12 套件 / 368 断言，约 10 秒）
node verify.mjs
```

## 你要做的只有 3 步

```powershell
# 1) 把 wechat-ai\ 整个目录拷到本机任意路径（解压即部署；无 . 前缀目录、无 node_modules）
Copy-Item -Recurse "D:\path\to\发布版本\wechat-ai" "D:\wechat-ai"
cd "D:\wechat-ai"

# 2) 跑安装器（环境检查 + 自检 + 自动注册到 Claude Code / Claude Desktop / Cursor）
node install.mjs

# 3) 重启 MCP 客户端，完成
```

看到这行就算成功：

```text
INSTALL_STATUS=OK TOOLS=63 PASS=94 FAIL=0 REG=auto
```

注册后对 AI 助手直接说人话即可（示例人名、群名均为虚构）：

- 「今天有什么要处理的？」→ 待回复、逾期承诺、临近截止的合并清单
- 「我和王总的合作聊到哪了？答应过什么？」→ 承诺清单与下一步
- 「帮我看看『AI 内训群』今天聊了什么重点」→ 群日报
- 「谁好久没联系、值得问候一下？」→ 复联雷达
- 「他刚回了我，怎么回合适？」→ 只出草稿，不发送

完整示例表见 README「自然语言使用示例」。

## 纯净包契约

- **无 `node_modules\`**：零 npm 依赖，不随包、不需要生成任何依赖
- **无 `.` 前缀目录**（`.git\` 等）；无凭据、无 `*.bak*` / `*.log` / `*.tmp` 残留
- `mcp-register.example.json` 不随包（机器绝对路径自动生成物），装机时 `install.mjs` 重新生成
- `samples\` / `docs\` / `verify.mjs` / `mcp\tests\` 随包保留（自验收依赖）
