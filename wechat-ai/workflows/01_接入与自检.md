# 工作流 01：接入与自检

## 适用场景

- 第一次使用本项目，需要把微信数据接进来。
- 换了机器、换了账号、微信升级后读取失败。
- 想确认当前环境是否健康（能不能出报告）。

## 前置条件

- 本机已安装 MCP 服务器（Node ≥ 22）。
- 至少有一种可用材料：已解密的 db_storage 副本、导出的聊天目录、可手动选中的聊天内容、外部只读 CLI，或允许用演示数据。
- 明确一条红线：本项目不获取密钥、不解密、不注入、不 Hook。

## 步骤

### 1. 看现状

    wai_status { }

关注三个数字：messages（索引里有多少消息）、last_index_ts（上次索引时间）、data_age_hours（数据年龄）。全为 0 说明还没接入。

### 2. 列出通道

    wai_sources { "probe": true }

结果里每一项都有 kind 与 available。能用的通道通常是：sqlite:<path>、vault:<dir>、cli:<id>、local、mock。

### 3. 定位卡点

    wai_access_plan { "databaseRoot": "D:/wechat/db_storage", "maxFiles": 500 }

返回的层级是：缺目录 / 缺密钥 / 依赖缺失 / 权限不足 / 可配置 / 就绪。

- 「缺密钥」不是你该解决的问题：改走 Inbox 或让用户自己准备已解密副本。
- 「权限不足」：确认当前用户对路径有读权限后重试，不要提权。
- 「可配置」：进入第 4 步。

### 4. 写入配置（按通道选一条）

    wai_config_set { "sqliteSources": [{ "id": "main", "path": "D:/wechat/db_storage", "enabled": true }] }
    wai_config_set { "vaults": [{ "id": "exports", "path": "D:/wechat/exports", "enabled": true }] }
    wai_config_set { "readers": [{ "id": "rion", "name": "外部只读 CLI", "command": "D:/tools/wechat-cli.exe", "args": [] }] }

不需要任何配置的通道是 Inbox：让用户在本机选中一段聊天，然后

    wai_inbox_push { "body": "<选中的原文>", "chat": "客户群A", "kind": "chat" }
    wai_inbox_process { "limit": 100 }

### 5. 建索引

    wai_db_index { "scope": "sessions", "sessionType": "private,group", "sessionLimit": 80, "perChatLimit": 500 }

- 想按标签收敛：scope: "labels", label: ["客户"]。
- 想按关键词：scope: "search", keywords: ["某产品"]。
- 只做演示：allowDemo: true（报告必须标注虚构）。

### 6. 验收读取

    wai_db_status { }
    wai_compat_check { "force": true }
    wai_self_test { }
    wai_reader { "command": "status" }

### 7. 端到端自检

    wai_doctor { }

diagnostics 里 level=error 必须处理；level=warn 需要在报告里说明。

### 8. 个性化（可选但推荐）

    wai_wechat_labels { }
    wai_profile_init { "ownerAlias": "我的微信名", "priorityLabels": ["客户", "品牌方"] }
    wai_profile_status { }

### 9. 隐私门禁

    wai_privacy_scan { }

## 验收标准

- [ ] wai_sources 里至少一个非 mock 数据源 available。
- [ ] wai_db_status 显示真实消息数 > 0，且数据年龄已知。
- [ ] 抽检一个已知会话，内容与微信里看到的一致。
- [ ] wai_compat_check 返回 ready，或写清 degraded 的原因与影响。
- [ ] wai_doctor 无 error。
- [ ] wai_privacy_scan 通过。
- [ ] Profile 状态与「是否使用默认口径」已写进结论。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 索引一直是 0 | 检查通道是否真的可用（probe），而不是只看配置里有没有写路径 |
| 路径存在但读不到 | 权限问题；修权限后重试，不提权、不换账号扫描 |
| 只有 mock 可用 | 先让用户用 Inbox 推一段真实内容，或提供导出目录 |
| 换了机器全空 | 正常：索引与 Profile 不跨机同步，重新配置即可 |
| 微信升级后失败 | 先降级到已有索引继续工作，在报告里标注截止时间 |
